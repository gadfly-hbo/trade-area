# 商圈对比分析 · 服饰门店选址

面向**线下服饰门店（成人装 + 童装）选址**的商圈对比分析网页。将多个商圈的 12 维度信息表（xlsx）横向对比，支持列表筛选、详情查看、2-4 商圈并排对比、可调权重的选址评分排名。

## 快速开始

```bash
npm install        # 安装依赖
npm run etl        # 解析 data/raw/*.xlsx → public/data/（索引 + 详情分片）
npm run dev        # 启动开发服务器
npm run build      # 类型检查 + 生产构建（产物在 dist/，可直接静态部署）
npm test           # ETL golden 测试（基于样本商圈）
```

## 数据接入

1. 把商圈 xlsx 放入 `data/raw/`（每个文件一个商圈，文件名建议 `NNN_商圈名.xlsx`，NNN 作为稳定 id）。
2. 运行 `npm run etl`，产物：
   - `public/data/index.json` — 全量摘要（数值指标 + 百分位分 + 默认评分）
   - `public/data/details/s{N}.json` — 详情分片（每 50 个商圈一片，按需加载）
3. ETL 会在终端输出解析报告：成功/失败数、指标抽取率、警告明细（维度缺失/重复等格式漂移）。

样本数据：`data/raw/003_湖州爱山广场.xlsx`。

## 架构

- **纯静态**：无后端，构建期打包数据，`dist/` 可部署到任意静态服务器。
- **前端**：React 19 + Vite 8 + TypeScript + Ant Design 6 + ECharts。
- **评分模型**：六因子（客流/3公里人口/客群匹配/租金/竞品/停车）加权百分位分，缺失因子权重按比例分摊；权重可在排名页调整并随 URL 分享。
- **数据出口**：`src/data/loader.ts` 是前端唯一取数模块，将来如换后端只改这里。

## 页面

| 路由 | 功能 |
|---|---|
| `#/` | 商圈列表：省市/评级/关键词筛选，指标排序，勾选加入对比篮 |
| `#/district/:id` | 详情：指标卡、森马三大人群、12 维度全文（来源 + 可信度标注） |
| `#/compare?ids=…` | 2-4 商圈对比：六因子雷达、客流/租金条形图、最优值高亮、维度对照表 |
| `#/ranking?w=…` | 选址排名：权重滑杆实时重算，全量排名 |

## 已知约定（数据修正）

- 爱山广场 2023 年零售额同比 **+11.3%**（147 → 163.6 亿元）。
- 「湖州站」区分普铁老站（约 11.7km）与沪苏湖高铁新站（约 3km，2024-12-26 开通）。
- 单店级销售/租金/坪效未公开的数据，界面统一显示「—」，不编造。
