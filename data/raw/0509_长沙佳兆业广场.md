# 修正点列表

1. **交通条件（关键事实性错误）**："2/6号线袁家岭换乘站" → "2号线袁家岭站"；并加注「袁家岭站为2号线单线站，2/6号线实际换乘站为相邻的迎宾路口站」。单站日均进出客流由 4–6 万下调至 2–4 万（单线 Line 2 中等量级站合理口径）。
2. **所在区位（数据不一致）**："长沙火车站约2–3km" → "约0.5–1.5km步行直达"；"芙蓉区政府约1km内" → "约1.5–2.5km"；移除易混淆的"湖南省政府约1.5–2km"（省政府位于天心区湘府路，距袁家岭实际约4–6km，不属于核心对标维度故删除）。
3. **最大优势（同步修正）**：#1"2/6号线换乘站" → "2号线站"，客流潜力"4–6万" → "2–4万"；#5"距长沙站500–800m" → "0.5–1.5km"，与所在区位一致。
4. **项目名称及地址**：补充"五一大道"为正式街道，"袁家岭地铁站4号口"作为地标补充。
5. **核心定位**：地址描述由"五一大道与蔡锷路交汇处"扩充为"五一大道与蔡锷路/车站北路交汇处附近"，更准确。
