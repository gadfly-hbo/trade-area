# 修正点清单

1. **「所在区位」「商业级别与体量」「开业时间」「周边3公里人口」「日均客流」「交通条件」「核心定位」**：均压缩至字数梯度上限以内（删减重复行政距离/辅路细节/二级品牌举例）。
2. **「商业级别与体量」**：将「58万㎡/60万㎡/30万㎡/12万㎡/13万㎡」统一表述为「总建面 58-60万㎡ → 商业面积 30万㎡ → 购物中心 12-13万㎡」三层级关系，避免读者误解为并列数字。
3. **「核心客群」**：删除与「森马三大人群」重复的「线下六大行业特色人群构成」段落，仅保留「常规客群分层 + 森马三大人群占比 + 构成说明」。
4. **「最大优势」「最大短板」**：合并为 4-5 个核心点，删除次要细节（如「盒马鲜生旗舰店」之外的具体品牌数），控制在 200 字内。
